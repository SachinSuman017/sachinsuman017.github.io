# Martin Yu · Punto en común

Ideas, proyectos y aprendizaje alrededor de negocios, información y tecnología.

[Recorrer la presentación](https://hightechbusiness.github.io/) · [Explorar proyectos](https://hightechbusiness.github.io/#proyectos)

## Los espacios del proyecto

- **Meli Propuestas · edición inicial:** generador público para preparar un PDF en español o chino. [Abrir](https://hightechbusiness.github.io/meli-propuestas-by-martin-yu/inicial/?inicio=1).
- **Meli Propuestas · edición del equipo:** la edición ampliada del mismo proyecto, con acceso verificado. [Conocer el espacio](https://hightechbusiness.github.io/meli-propuestas-by-martin-yu/equipo/).
- **Punto en común:** este portafolio reúne el origen, las decisiones, el progreso y las exploraciones visuales. Se mantiene en evolución.

Las dos ediciones de Meli Propuestas pertenecen al mismo proyecto; no se cuentan como productos independientes. Los estados describen funciones disponibles y trabajo pendiente, sin porcentajes de avance ni resultados comerciales supuestos.

## El recorrido

Necesidad → personas → objetivo → plan → herramienta → aprendizaje.

La presentación se puede explorar con scroll o con un recorrido automático que comienza al pulsar su botón y permite pausar y continuar. Incluye una vista de lectura libre cuando el sistema solicita movimiento reducido.

## Alcance público

Este repositorio contiene sólo la presentación estática. No contiene el maestro interno de tasas, datos de clientes, registros de actividad del equipo, credenciales ni respaldos operativos. No incorpora un contador ni envía eventos de uso a un servidor propio.

Hoy trabajo en Mercado Libre. Este espacio es un proyecto personal e independiente; no es un sitio oficial de Mercado Pago ni representa una oferta de consultoría.
